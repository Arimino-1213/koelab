# こえラボ（声の編集アプリ）

`index.html` をダブルクリックで Chrome / Edge を開けば使えます。インストール不要。

## できること

**① 分析・変換**（APIキー不要・ファイルはパソコンの外に出ません）
1. 音声・動画をドラッグ＆ドロップ（またはマイクで録音）
2. 分析：長さ／声の高さ（Hz・抑揚）／音量（LUFS）／音割れ／無音の割合／背景ノイズ → 診断とおすすめ設定
3. 変換：声の高さ・速さ・ノイズ除去・無音カット・音量そろえ・音色・響き・キャラ（ロボット／電話／ラジオ／拡声器）
4. 書き出し：WAV／MP3／動画（元の映像＋変換後の音）

波形をドラッグすると、その範囲だけを分析・変換できます。

**② 台本から声を作る**（Gemini APIキーが必要。右上の ⚙設定 で入力）
- 1行ずつ演技指示（ささやくように、笑いながら…）をつけて読み上げ
- 1人の語り／2人の掛け合いを1回で生成
- 読み上げる言語を「日本語／English／中文（簡体字・普通話）」で切り替え（台本カード右上）。中文の動画字幕は Noto Sans SC で描く。見本の台本・演技指示の候補・入力例・字幕合わせの文字起こし・動画の「AI音声／AI voice」表示が連動。画面の表示は日本語のまま
- 「見本の台本を入れる ▾」で見本を選べる（日本語・英語・中文それぞれ：ナレーション／日常の掛け合い／謝罪会見（プリンの件）。日本語には宣伝用の「こえラボ紹介」もあり、動画のタイトルとラベルも入る）
- 「声の説明」で声の人物像を指定（ボイスデザイン）
- 生成した声は「① 分析・変換で開く」でそのまま加工できる
- **解説動画にする**：波形アニメ＋字幕（話す人・演技指示つき）の動画を mp4 で保存。横長 1920×1080／縦長 1080×1920
  - 字幕の切り替えは、音声を「間」で細かく区切って文字起こしし、台本の各行と照らし合わせて決める（切れ目は必ず間に置く）。字幕の文字が濃くなる速さも、区切りごとの時刻に合わせる
  - 文字起こしできないときは、声の「間」と各行の文字数から推定する方法に戻る（行ごとに話す速さが大きく違う台本ではずれやすい）
  - 1コマずつ作るので再生時間より速く仕上がる（15秒の動画で約6〜7秒）。Chrome / Edge が必要
  - 「動きのある演出を付ける」（初期値オン）：行ごとに、見出し・数字（カウントアップ）・札を順に並べる・会話の吹き出し・寄りで強調・絵文字、のどれかが声に合わせて動く。「AIで演出を考える」で Gemini が台本から行ごとの演出を決める（API が使えないときは台本から自動で決める簡易版）。「演出の編集」で行ごとに型・画面に出す言葉・絵文字を直せる。見本「宣伝：こえラボ紹介」には演出が最初から付いている
  - 「行ごとの字幕のタイミングと演出」の一覧で、各行の字幕の開始時刻を −／＋（0.1秒ずつ）で手で直せる。時刻を押すとその行から再生。文字起こしが使えず字幕が目安のまま（Gemini の無料枠切れなど）で書き出そうとすると確認が出る
  - 字幕の切り替えがずれたときは、開発者ツールのコンソールに「[こえラボ] 字幕合わせ」として各行の開始時刻と断片ごとの文字起こしが出る
  - 「透かし」に `@アカウント名` などを入れると、動画の縁（右下・左下・右上・左上・下の中央）に半透明で入る。初期値は空欄（入力した値はそのブラウザに保存）

**自分の声を登録**（Gemini 3.8 の Voice Replication）
1. 自分の声の見本を10〜30秒録る（またはファイル）。24kHzモノラルWAVに変換し、前後の無音を落として30秒以内に切り出す。長さ・雑音・音割れ・音量を自動チェック
2. 同意文「私はこの音声の所有者であり、Googleがこの音声を使用して音声合成モデルを作成することを承認します。」を、見本と同じ環境で読み上げて録る
3. 「声を作る」→ `voice_…` の番号ができ、声のプルダウンの「自分の声」に出る（1年保存。外すと7日で消える）。削除もできる
- 登録できるのは本人の声だけ（見本と同意の声を Google が照合する）。他人の声は登録しないこと
- 自分の声は 3.8 の読み上げモデルでだけ使える
- 同意文は日本語・英語のみ（中国語の正確な文面は未確認のため未対応）
- 読み上げ言語を指定する項目は API にない（9/27 に全階層を確認）。そのため中文・英語では各行の指示の先頭に「请用标准普通话朗读…」「Speak in natural English」を付ける。人物像や雰囲気に日本語（かな）が入っていると警告する（日本語読みが混ざる原因になる）
- Google の標準の声の一覧（2,089個）に中国語専用の声はない。中国語は Kore などの多言語の声で読む
- 同意の録音は、送る前に Gemini で文字起こしして画面の文と一致するか確認する（ずれていれば録り直し）
- 声の言語（`voice.language_code`、日本語なら ja-JP）を一緒に送る。送らないと日本語の同意文が「一致しない」と弾かれることがあった
- 失敗したとき Google は「Error translating server response to JSON」という中身のない文面を返すことがある（Google側の不具合）。アプリは奥にある本当の理由を取り出して日本語で表示する
- マイク録音は、Claude のアプリ内ブラウザでは使えない。Chrome / Edge で開くこと

①の「AIで文字起こし・話し方診断」も同じキーで使えます。

## 注意
- 処理はモノラルです（ステレオは混ぜて1chにします）
- 動画の書き出しは再生しながら録画するため、動画の長さぶん時間がかかります。「無音をつめる」を使った場合は映像と長さが合わないので動画書き出しはできません
- MP3書き出し・解説動画はインターネット接続が必要（部品を CDN から読み込むため）
- Geminiのモデル名は ⚙設定 の「使えるモデルを取得」で最新のものを選べます（初期値 gemini-3.8-flash-tts / gemini-3.8-flash）
- Gemini 3 系の読み上げは新しい `POST /v1beta/interactions` 形式で送ります（行ごとに話す人と演技指示＝style を付ける）。2.5 系は従来の generateContent 形式
- 「声の説明」は現在、各行の演技指示と一緒に渡しています。公式の「ボイスデザイン」（`POST /v1beta/voices` で声そのものを作る）は送り方の例が未公開のため未対応

## ファイル
- `index.html` 画面 / `app.js` 画面の動き / `dsp.js` 音声処理（外部ライブラリなし）/ `video.js` 解説動画の描画と mp4 書き出し（mp4-muxer を jsdelivr から読み込む）
- `tests/dsp.test.js` 音声処理のテスト（`node tests/dsp.test.js`）
- `tests/samples/` 検証用の音声・動画（Windows読み上げ Haruka で作成）
